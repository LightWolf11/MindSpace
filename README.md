#### Цель работы: Разработайте интерактивный планировщик задач проекта. Реализуйте создание задач с указанием приоритета, срок выполнения, текущего статуса и зависимости от других задач. Предусмотрите изменение статуса задач и информирование пользователя о невозможности начать выполнение задачи при наличии незавершенных зависимостей. Предусмотрите визуальное выделение просроченных и высокоприоритетных задач. Представьте статистику выполнения проекта. 

Тестить сайт тут - lightwolf.ru / www.lightwolf.ru

Планировщик задач с зависимостями, сроками, приоритетами и проектной статистикой. Интерфейс и REST API запускаются одним Node.js/Express-сервером и хранят данные в MySQL. API можно проверить импортированной коллекцией Postman.

Пользователь видит свои проекты и проекты, к которым присоединился через приглашение. Владелец назначает участникам `editor` (изменение задач) или `viewer` (только чтение). Пригласить можно уже зарегистрированного пользователя по его email; приглашение показывается внутри приложения, почтовый сервер не используется. Только владелец управляет участниками и удаляет проект; перед удалением нужно ввести название проекта и пароль аккаунта. При удалении также удаляются задачи, метки, зависимости, участники и приглашения проекта. Название и цвет проекта можно изменить через меню действий проекта. Участник может выйти из проекта. После регистрации новый аккаунт получает пустое рабочее пространство.
